If the team will collect or request assets in phases, this is the recommended order:

1. Real photos for all ministries that still use AI-generated placeholders
2. Real photos for service pages: Baptism, Confirmation, Funeral Services, House Blessings
3. Real photos for the Marriage page hero and section images
4. Historical / archival photos for the About History timeline
5. Additional clergy profile photos for the About page
6. Replacement of remote-hosted gallery, schedule, and diagram assets with parish-owned files if long-term asset control is required
